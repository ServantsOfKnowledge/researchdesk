# Library folder

Put IA-style item folders here (or point `LIBRARY_DIR` in `.env` at another folder, a USB disk
or a mounted NAS share). Inside Research Desk this folder is `/library-source`.

```
library/
  mybook0001/
    mybook0001_meta.xml
    mybook0001_hocr_searchtext.txt.gz + mybook0001_hocr_pageindex.json.gz   (or _hocr.html, _chocr.html.gz, _djvu.xml, _djvu.txt)
    mybook0001.pdf
    __ia_thumb.jpg
```

See docs/local-folders.md.
